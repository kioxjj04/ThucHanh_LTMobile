# Lab 05 - Thực hành React Native & Expo Router

Bài tập thực hành Lập trình Thiết bị Di động (Mobile Development).

## Cấu trúc thư mục Lab 5
Dự án bao gồm 5 bài tập:
- **Bài 1: Ứng dụng Select Phone**: Màn hình xem chi tiết điện thoại Vsmart Joy 3 và chọn màu (Bạc, Đỏ, Đen, Xanh), truyền tham số màu qua Expo Router.
- **Bài 2: Gắn API**: Tải và hiển thị thông tin sản phẩm từ MockAPI (`fetchPhoneFromApi`).
- **Bài 3: Bottom Tab Navigation**: Điều hướng 3 tab Home (FlatList), Search (TextInput), Profile (Avatar và thông tin cá nhân).
- **Bài 4: Stack + Tab Navigation**: Kết hợp Stack và Tab (Products, Favorites), truyền param `id` sang màn hình Product Details.
- **Bài 5: Drawer Navigation**: Menu trượt từ cạnh trái với 3 màn hình Home, Profile và Settings (Switch bật/tắt).

## Hướng dẫn cài đặt và chạy

1. Di chuyển vào thư mục `Lab5`:
```bash
cd Lab5
```

2. Cài đặt các thư viện phụ thuộc:
```bash
npm install
```

3. Chạy ứng dụng trên trình duyệt web:
```bash
npx expo start --web
```
Hoặc quét mã QR bằng ứng dụng **Expo Go** trên điện thoại.
